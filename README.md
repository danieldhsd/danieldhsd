### 👨‍💻 About Me

- 🎓 Graduated in **Computer Science** at *Universidade de Itaúna*.
- 📍 Based in **Belo Horizonte, MG — Brazil**.
- 💼 Backend Software Engineer focused on designing and building scalable, resilient enterprise applications with **Java** and the **Spring Ecosystem** (`Spring Boot`, `Spring Security`, `Spring Data JPA`).
- 🏛️ Passionate about **Clean Architecture**, **Domain-Driven Design (DDD)**, design patterns, and writing clean, maintainable, testable code.
- ☁️ Actively expanding in **DevOps & Cloud-Native** technologies: Docker, Kubernetes, CI/CD pipelines, and observability.
- 🌐 Experienced with fullstack integrations using modern web technologies (**React**, **TypeScript**, **Tailwind CSS**).
